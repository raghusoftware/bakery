# FastBill POS — API

The backend is **Supabase**, so REST is auto-generated by **PostgREST** from the
schema. Every table is an endpoint; RLS scopes rows to the logged-in shop
(`owner = auth.uid()`), so no request ever needs to send an owner filter.

Base URL: `https://<project>.supabase.co`
Every request sends:

```
apikey: <publishable key>
Authorization: Bearer <user access token>   # from supabase.auth
```

## Generic CRUD (applies to every feature/table)

| Action | Method + path | Notes |
|--------|---------------|-------|
| List   | `GET /rest/v1/<table>?select=*&order=id` | add `&col=eq.value` filters |
| Create | `POST /rest/v1/<table>` body `{...}` | `owner` auto-filled by default |
| Update | `PATCH /rest/v1/<table>?id=eq.<id>` body `{...}` | |
| Delete | `DELETE /rest/v1/<table>?id=eq.<id>` | |

With the JS SDK these are `sb.from(table).select() / .insert() / .update().eq() / .delete().eq()`.

## Per-feature endpoints

**Sale screen**
- `GET /rest/v1/products?select=*` — item list for the grid
- `POST /rest/v1/sales` — record a sale (`items` jsonb, totals, pay_mode…)
- Stock deduction on sale: `PATCH /rest/v1/products?id=eq.<id>` `{stock_qty}` (or batch)
- Credit sale → also `POST /rest/v1/receivables`

**Production / recipe (inventory auto-deduct)**
- `POST /rest/v1/rpc/produce_batch` body `{ "p_product_id": 4, "p_qty": 50 }`
  → atomically deducts ingredients, adds finished stock, logs the batch, returns log id.
- Recipe CRUD: `/rest/v1/recipes`

**Staff (salary advances + payable balance)**
- Staff CRUD: `/rest/v1/staff`
- Give advance: `POST /rest/v1/advances`
- Attendance: `POST /rest/v1/attendance`
- Payable balance is **derived** (earned − advances) — computed client-side or via a view.

**Suppliers**
- CRUD: `/rest/v1/suppliers`

**Stock inward (linked to inventory)**
- `POST /rest/v1/purchases` (the bill) **and** `PATCH /rest/v1/raw_materials?id=eq.<id>` `{stock_qty += qty}`
- Supplier payment: `POST /rest/v1/supplier_payments`

**Payables (separate staff & supplier ledgers)**
- Supplier dues: unpaid `GET /rest/v1/purchases?paid=eq.false` minus `supplier_payments`
- Staff dues: `GET /rest/v1/advances` and `attendance` (derived)

**Expenses**
- List: `GET /rest/v1/expenses?select=*&order=date.desc`
- Add: `POST /rest/v1/expenses` `{amount, category, note, date}`
- Filter by month: `GET /rest/v1/expenses?date=gte.2026-07-01&date=lt.2026-08-01`

**Products (image upload)**
- CRUD `/rest/v1/products`. `image` stores a URL (recommended: Supabase Storage
  public URL) or a base64 data-URI blob for small thumbnails.
- Storage upload: `sb.storage.from('product-images').upload(path, file)` → `getPublicUrl(path)`.

## Auth
- `sb.auth.signUp({email,password})` / `signInWithPassword` / `signOut`
- Session token is attached automatically by the SDK to every request above.
